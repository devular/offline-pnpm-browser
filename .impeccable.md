# Design Context

## Target Audience
Developers exploring their local pnpm package cache offline. Technical users who appreciate information density, fast navigation, and clear typography. People who spend hours in terminals and code editors — they value utility over decoration.

## Use Cases
- Search and browse ~10,000 npm packages cached locally
- Understand package relationships (dependencies, dependents)
- Read package READMEs to evaluate libraries
- Navigate dependency graphs by clicking through connections

## Brand Personality / Tone
**Futuro-Bauhaus**: The rigor and geometric clarity of Bauhaus — form follows function, every element earns its place — merged with a futuristic sensibility. Think: a developer tool designed by Dieter Rams if he worked at a space agency. Clean geometric forms, functional typography that communicates hierarchy through weight and scale rather than decoration, a restrained palette with high-contrast accent moments. The interface should feel like a precision instrument — engineered, not decorated.

## Aesthetic Direction
- **Typography**: Strong geometric sans-serif. Hierarchy through size and weight contrast, not color.
- **Color**: Near-monochrome foundation (warm off-blacks and cool off-whites) with a single sharp accent color for interactive elements. No gradients, no glows.
- **Layout**: Asymmetric grid with generous whitespace. Left-aligned. Content breathes.
- **Details**: Thin rules as dividers. Uppercase micro-labels. Tabular numbers. Monospace for package names and versions.
- **Motion**: Minimal. Fast transitions (100-150ms). No bounce, no spring. Things appear, they don't animate in.

## What Makes It Memorable
The confidence of restraint. Every pixel is intentional. It should feel like the interface was designed by someone who said "no" to 90% of possible features and ornaments.
